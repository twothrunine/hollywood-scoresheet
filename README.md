Hollywood Gin Rummy Scoresheet
A sophisticated web app for tracking Hollywood-style gin rummy scores with monetary tracking.
Features

Hollywood Scoring System: Each player's wins progress through three simultaneous games

1st win → Game 1 only
2nd win → Games 1 and 2
3rd+ wins → All three games


Session Balance Tracking: Keep running totals of winnings/losses across multiple rounds
Customizable Values: Set your own winning score, game value, and box value
Shutout Bonus: Automatic doubling of payouts when opponent scores zero
Persistent Data: All scores and settings save automatically using local storage
Progressive Web App: Install on your phone for an app-like experience
Works Offline: Access your scoresheet anytime, no internet required

How to Use
As a Web App
Visit the live app: https://twothrunine.github.io/hollywood-scoresheet
Install on iPhone

Open the app in Safari
Tap the Share button (square with arrow)
Select "Add to Home Screen"
Tap "Add"

The app will now appear on your home screen like a native app!
Gameplay

Select which player won the hand
Enter their points
Click "Add" to record the score
Scores automatically distribute to the appropriate games based on Hollywood rules
When a game reaches the winning score (default 100), it calculates payouts including:

Base game value
Box bonuses for hand difference
Shutout doubling if opponent never scored



Default Settings

Winning Score: 100 points
Game Value: $5.00 per game
Box Value: $1.00 per hand difference

All settings can be customized by clicking the gear icon.
